# Clinic FAQ

The shared homepage menu links to the standalone /faq/ page. The server-rendered view in `src/views/faq/index.tsx` reuses the eight questions in `src/data/mocks/faq.ts`. Native disclosures start collapsed, allow one open answer at a time, and work with pointer and keyboard. The account answer links to /register/.

The page uses the existing FAQ colors, typography, spacing, and disclosure styles. Its home link returns to the landing page.
