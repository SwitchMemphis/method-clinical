# Mint Clinical

Source for the Mint Clinical website at [mintclinical.com](https://mintclinical.com/). Netlify deploys the `main` branch to the [mintclinical production project](https://app.netlify.com/projects/mintclinical/deploys).

## Getting started

Use Node.js 22.13 or later and Yarn Classic 1.22.22.

```sh
yarn install --frozen-lockfile
yarn dev
```

Open [localhost:3000](http://localhost:3000) for local development. Run `yarn lint` to check the source and `yarn build` to generate the static site in `out/`.

See [project status](PROJECT-STATUS.md) for recent changes and the [project documentation](obsidian/README.md) for architecture and development conventions.
